
# Student Grade Management System

## Project Overview
A web-based application for managing student academic records and calculating grades.

## Project Purpose
The system helps administrators manage student information, monitor academic performance, and calculate academic results.

## Key Features
- Add student records.
- Edit student information.
- Delete student records.
- Calculate total and average grades.
- Assign letter grades (A, B, C, D, F).
- Determine pass or fail status.
- Search students by name or ID.
- Display class statistics.
- Save records using Local Storage.
- Responsive user interface.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Browser Local Storage

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Project Structure
- index.html: Application structure.
- style.css: Application design.
- script.js: Application functionality.
- README.md: Project documentation.
- .gitignore: Git ignored files.

## Git Workflow
This project follows Feature Branch Workflow.
Changes are developed in separate branches,
committed, pushed, reviewed through Pull Requests,
and merged into the main branch.

## Data Storage
Student records are stored locally in the browser
using Local Storage.

## Limitations
- Data is stored in the current browser only.
- Records are not shared between devices.
- The application does not include user authentication.
